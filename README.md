## 使用

1. 退出游戏，完整解压；EXE 与同名 `.exe.config` 保持在同一目录。
2. 运行 `EndfieldModRepair.exe`，选择 EFMI、Mods 或上级 XXMI Launcher 文件夹。
3. 先点“仅扫描”看报告，再点“一键备份并修复”。没有匹配规则的项目不会强行写入。
4. 重新启动带模组的游戏，检查近景、远景、动作和服饰切换。配置写入完成不等于游戏兼容验证通过。
5. 若异常或闪退，退出游戏，点击“撤销/恢复上次修改”；保留报告和 `_ModRepairBackups`。

Windows 10/11，.NET Framework 4.8，无需安装 Python，无联网功能。不修改 XXMI 启动方式、游戏文件、模型或贴图；不包含卡顿或底层 DLL 优化。

## 本次修复

- 珊瑚海岸保留作者原绘制方式，修正身体材质绘制前错误清空新版光照贴图的问题。
- xoxo 收录对应顶点与深度通道适配、身体光照贴图绑定；保留作者面板、模型和切换按键。
- 墨雪礼服使用本模组局部阴影标记，避免全局改写其他模组依赖的通道编号。
- RabbitFX 根据资源接口、提交条件和特效模板检查兼容性，不依赖版本号注释或某条旧正则原文。已测试 2.7、4.2 以及多种格式变体；未知接口会停止相关写入。
- 需要改共享 RabbitFX 时，若其他启用配置尚未确认，整批停止。已验证的共享配置可以保持原样。
- 发际线、衣缘出现点状黑边时，报告读取 RabbitFX 自带反虚化按键供核对；不强行更改用户开关状态。本次实测通过反斜杠键 `\` 开启反虚化后消失，其他包以报告显示的实际键为准。

## 防误改与恢复

写入前复核 INI 清单与内容、关键模型及骨架资源，按整组校验输出。支持备份、原子写入、写入失败回滚及中断恢复；重复运行不会再次偏移已匹配的参考配置。互斥服装同时启用时停止修改。部分参考包原有缺失资源声明会在报告注明，工具不补图，相关作者选项仍需游戏检查。

支持恢复 v1.0 / v1.1 / v1.2 的备份与中断记录。损坏的备份和后来被其他工具改动的文件不会强行覆盖。没有原始备份时不能仅凭修复注释还原，需要作者原包。

**v1.2 有误改风险，请停止用旧版批量修复。** 已用构造配置复现重复偏移；没有取得反馈者的原包，尚未复现其具体闪退。若旧版改坏后不匹配新版规则，先用撤销恢复功能，不要反复叠加修复。
