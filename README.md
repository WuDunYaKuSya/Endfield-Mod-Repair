# EFMI 修改撤销与恢复

**v1.2 已收到误改反馈，请暂停使用旧版对整套 Mods 批量写入。**

旧版的固定贴图槽位统一偏移没有充分判断作者是否已经适配，可能再次修改本来正常的配置。已用构造配置复现重复偏移；还未取得反馈者原包，未复现其具体闪退。“配置写入完成”不等于“游戏兼容验证通过”。

## 下载撤销恢复工具

[下载 EFMIRepairRecovery-v1.2.1.zip](https://github.com/WuDunYaKuSya/Endfield-Mod-Repair/releases/download/v1.2.1/EFMIRepairRecovery-v1.2.1.zip)

[查看 v1.2.1 发布说明](https://github.com/WuDunYaKuSya/Endfield-Mod-Repair/releases/tag/v1.2.1)

此程序只撤销旧修复工具的修改，**不执行新的模组适配**，不是新的通用修复版。

1. 退出游戏和其他修复工具窗口，完整解压。
2. 运行 `EFMIRepairRecovery.exe`，选择原来修复的 EFMI 目录，也可选择 Mods 或上级 XXMI Launcher。
3. 点击“撤销/恢复上次修改”。若执行过多次修复，可继续按从新到旧逐批撤销。
4. 重新启动游戏验证。仍异常时，导出恢复报告并保留备份。

## 恢复范围

依据 `EFMI/_ModRepairBackups` 的清单和前后校验值恢复原始 INI，清理对应批次由工具新增的规则文件。支持已完成的修复，以及部分文件已恢复、部分仍被修改的中断状态。

后来被用户或其他工具修改的文件不会强行覆盖，损坏的备份不会使用。没有原始备份时无法只凭“修复标记”推导原始配置，需要使用作者原包恢复。

本程序不改 XXMI 启动设置、模型、DDS 或游戏文件，不会把已经恢复的文件重新补回。它也不能自动撤销其他工具或人工修改。

## 验证与环境

20 项恢复机制检查与 5 项独立程序检查通过，另有原有 45 项离线检查通过。已验证真实旧 v1.2 程序产生的备份可以逐字节撤销，包括新增规则清理。**这些检查没有复现反馈者未知模组的具体闪退，恢复后仍需在游戏中验证。**

Windows 10/11，.NET Framework 4.8，无需 Python。EXE 与同名 `.exe.config` 保持同目录。源码、构建脚本、完整说明与校验表均在压缩包内，源码采用 MIT 许可证。

仓库保留的 `EndfieldModRepair-v1.2.zip` 是有上述已知风险的历史原包，保留供核对，不建议继续批量使用。本仓库不包含原始 RabbitFX 或第三方模组资源。
