# 终末地模组兼容修复 v1.2

Windows 图形界面工具，用于适配 2026-10-15 更新后的已识别模组配置。此仓库仅发布 v1.2 安装包，源码及详细说明已包含在压缩包内。

## 下载和使用

下载本仓库的 **EndfieldModRepair-v1.2.zip**，也可以在 **Releases** 中下载同名文件。

1. 完整解压，运行 `EndfieldModRepair.exe`。
2. 选择 `EFMI` 文件夹，先点击“仅扫描”查看结果。
3. 点击“一键备份并修复”，完成后进游戏按 F10，检查角色显示。
4. 需要撤销时，选择同一文件夹并点击“还原上次修复”。

支持 Windows 10/11 与 .NET Framework 4.8，无需 Python。EXE 和同名 `.exe.config` 请保持在同一文件夹。

## 修复范围

- 按 RabbitFX 资源接口和特效模板判断兼容性，不依赖版本号白名单。
- 固定贴图槽位适配、RabbitFX 深度通道贴图同步，以及已识别的陈千语配置修复。
- 修改前自动备份，支持重复运行和逐次还原。

真实样本验证覆盖 RabbitFX 2.7 与 4.2 Experimental 4；其他版本沿用相同接口时可以走同一适配路径。资源接口不同或无法安全迁移的配置会提示并跳过。不能保证所有未知版本、未来版本或所有模组均兼容。

本版本处理显示兼容问题，不包含卡顿或底层 DLL 优化。新增跨版本路径已经离线测试，使用后仍需在游戏中核对效果。

## 备份与许可

备份保存于所选 EFMI 目录下的 `_ModRepairBackups`。工具不更改 XXMI 启动设置。
